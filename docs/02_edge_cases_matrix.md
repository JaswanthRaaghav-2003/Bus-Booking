# Part 2: Comprehensive Edge Cases Matrix (38 Scenarios)

This test matrix covers all twelve failure domains specified in the BusLane requirements, plus the ten high-risk edge cases explicitly identified by the audit committee.

**Severity Standards**:
- **High**: Money lost, seat double-sold, payment without ticket, unrefunded late charge, customer PII exposed, or bus seat blocked permanently.
- **Medium**: Incorrect application behavior or inconsistent UI state, but booking/refund completes safely without financial or data corruption.
- **Low**: Cosmetic anomaly, minor visual glitch, or non-blocking UI copy discrepancy.
